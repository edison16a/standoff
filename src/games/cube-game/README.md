# Cube Game

Status: in development.

## The idea

A rhythm platformer in the spirit of Geometry Dash, played with your body in front of the computer's camera: jump for real and the cube jumps. 3D graphics seen from the side, so it reads like a 2D game, with music synced to each level and all the sound effects.

* **Players:** 1, or 2 in split screen.
* **Control:** jump. The camera and the shared pose model (`src/games/kit/camera`) read the jump.
* **Modes:** the cube (jumps), the UFO (each jump flaps it up), and the ball (each jump flips gravity).
* **Levels:** five, from easy to hard, each with its own music and look.
